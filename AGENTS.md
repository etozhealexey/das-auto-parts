# Правила работы в Das-Auto-Parts

Перед работой прочитай [AGENT_CONTEXT.md](AGENT_CONTEXT.md). Это постоянная память проекта:
договорённости пользователя, архитектура, состояние реализации, проверки и журнал задач.
После выполненной задачи или нового существенного решения обнови этот файл до завершения работы.
Инструкции запуска и настройки находятся в [README.md](README.md).

- Пользовательские сообщения и проверенный исходный код имеют приоритет над сохранённым контекстом.
  Проверяй текущее состояние Git и окружения; старую проверку не выдавай за новую.
- Коммиты и push делать после явного поручения пользователя. 09.11.2026 пользователь
  разрешил commit и push накопленных доработок текущего этапа; это заменяет прежний запрет
  для этой публикации. Указание remote само по себе не даёт разрешение на новые публикации.
- Сохраняй незакоммиченные изменения предыдущих этапов. Не откатывай и не перезаписывай их
  при начале новой задачи. Разрешения из avia и других проектов сюда не переносятся.
- Если нужны дополнительные агенты, пользователь разрешил только Opus; Fable запрещён.
  Если Opus недоступен, выполняй работу самостоятельно.
- Ключи, пароли, приватную ссылку прайса и содержимое `.env` не выводить в чат, логи или документы
  и не добавлять в Git. В контексте хранить только имена настроек и факт наличия доступа.
- При локальной разработке и тестировании оставлять `SUPPLIER_ORDERS_ENABLED=false`.
  Отправка заказа в Автоевро — реальная операция; проверять её на поддельном провайдере.
- Сохранять согласованные правила: цена +15%, срок +1 день, поставщик виден пользователю,
  заказы всех клиентов направляются через общий аккаунт бизнеса при включённой отправке.
- Не считать VIN-подбор подключённым: для CarsCats ещё нужны доступ и подтверждённый способ
  интеграции с сайтом. Не подменять его поиском названия машины в прайсе.

При обновлении контекста указывай цель задачи, изменённые файлы, решения, проверку, ограничения
и отдельно статус commit/push/deploy. Историю сохраняй, отменённые решения явно помечай.
